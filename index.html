working on

Two directions with one thesis: research gets faster when the loop from question to result is automated and cheap to run.

01 · Autonomous research

Discovery OS

Can AI agents do real research? A workbench where agents read the literature in full, plan experiments, run them in a sandbox and report results that trace back to the code and data behind them.

02 · Energy-first inference

MilliJoule

What does LLM inference look like if energy is the main metric? An engine that aims for as few joules per output token as possible on modern GPUs, measured with real hardware counters.

Principles

How we work

01

Evidence over claims

Every result traces back to the code, data and run that produced it. Agents have to show their work too.

02

Measure what matters

We benchmark against held-out tasks and real hardware counters, not proxies that are easy to game.

03

Efficiency is a feature

Compute and energy cost are first-class numbers we track and report, not something left for later.
