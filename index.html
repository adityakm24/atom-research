Deep research lab

Machines that do science, efficiently.

Atom Research works on autonomous research agents and the inference infrastructure that runs them. We want each experiment to need less human effort, and each answer to use less energy.

What we're working on

Two directions with one thesis: research gets faster when the loop from question to result is automated and cheap to run.

Autonomous research

Discovery OS

Can AI agents do real research? We're building a workbench where agents read the literature in full, plan experiments, run them in a sandbox and report results that trace back to the code and data behind them.

Open questions we're working on: how to stop agents fooling themselves, how lessons from one project should carry over to the next, and how a person can steer a long investigation without restarting it.

Energy-first inference

MilliJoule

What does LLM inference look like if energy is the main metric? We're building an inference engine that aims for as few joules per output token as possible on modern GPUs.

The work spans the scheduler, memory management and GPU kernels, all measured with real hardware energy counters rather than estimates.

How we work

Evidence over claims

Every result traces back to the code, data and run that produced it. Agents have to show their work too.

Measure what matters

We benchmark against held-out tasks and real hardware counters, not proxies that are easy to game.

Efficiency is a feature

Compute and energy cost are first-class numbers we track and report, not something left for later.
