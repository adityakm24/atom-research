02 · Energy-first inference

MilliJoule

An AI inference engine built around one number: the energy it takes to produce each word.

The problem

Every AI answer costs energy. As AI use grows, so does the bill, yet today's engines are tuned for speed, not energy.

Our answer

Start from the joules

MilliJoule judges every design choice by the energy per word it produces, measured on the chip itself, at the speed users expect.

Architecture

Where the
joules go

Energy is spent at every stage of serving a request, so we build and measure the engine as one system.

01

Scheduler

Keeps the chip busy by serving many requests together.

02

Memory

Reuses work already done instead of computing it again.

03

Kernels

The core maths, chosen for energy, starting with mixture-of-experts models.

04

Hardware

Uses what each chip offers rather than the lowest common denominator.

05

Meter

Reads the chip's own energy counters on our benchmarks.

Method

How we
measure

  • M1
    Measure on the hardwareEnergy comes from the chip's own power counters.
  • M2
    Respect the noiseA gain only counts if it is bigger than the measurement error and holds up on a repeat run.
  • M3
    Never quote a number aloneEvery figure comes with its chip, model and speed target, so it can't be compared unfairly.
  • M4
    Count idle powerA real server spends time waiting too, so we include it.
